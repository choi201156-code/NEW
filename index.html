관심 분야와 키워드

분야를 만들고 키워드를 넣으면, '분야별' 화면에서 그 분야의 뉴스·많이 인용된 해외 매체·관련 지표·논문을 모아 보여줘요.

기타 키워드 분야 없이 받아볼 단어

  1. 저장하기를 누르면 설정이 복사되고 GitHub 편집 화면이 새 창으로 열려요.
  2. 편집 칸을 클릭 → Ctrl+A → Ctrl+V → 초록 Commit changes 두 번
  3. 아래 'GitHub 연결'을 해두면 이 과정 없이 버튼 한 번으로 저장돼요.
🔗 GitHub 연결

연결하면 ① 설정 저장이 버튼 한 번으로 되고 ② 이슈 노트를 GitHub에 보관해서 다른 기기에서도 볼 수 있어요.
토큰 만들기: GitHub → 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access: Only select repositories에서 이 사이트 저장소(노트용 저장소를 따로 만들었다면 그것도) 선택 → Permissions → Repository permissions → Contents: Read and write → Generate

⚠ 공개(Public) 저장소에 노트를 저장하면 누구나 볼 수 있어요. 노트는 비공개(Private) 저장소를 하나 새로 만들어서 그 이름을 적는 걸 추천해요. 토큰은 이 브라우저에만 저장돼요.
