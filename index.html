AI와 대화하며 키워드 찾기

공부 중인 자료를 넣고 대화하면, AI가 관심사를 찾아 뉴스 키워드를 추천해요. 추천 키워드를 누르면 내 키워드에 추가돼요.

🔑 AI 연결 설정

발급: platform.claude.com → API Keys.

챗쿠 크레딧이 차감돼요. PDF·Word는 글자만 뽑아서 보내고, 이미지는 보낼 수 없어요.

챗쿠 API 키 받는 법 (경희대 구성원)
  1. chat.khu.ac.kr에 인포21 아이디·비밀번호로 로그인해요. (경희대 통합앱, info21.khu.ac.kr 바로가기로도 들어갈 수 있어요)
  2. 챗쿠 메뉴에서 API 키 발급·관리로 가서 새 키를 만들어요. 메뉴 위치가 헷갈리면 챗쿠 게시판의 안내 매뉴얼·FAQ를 보세요.
  3. 발급 화면에 나온 키와 요청 주소(Base URL)를 위 칸에 붙여넣어요.
  4. 모델 목록 불러오기를 누르고 모델을 골라요. 무료 모델(예: GPT-5 nano, Solar Pro)은 크레딧이 안 줄어요.
  5. 저장을 누르면 끝이에요.

학생은 매달 2,000 크레딧이 들어와요. 사용량은 챗쿠 마이페이지에서 볼 수 있어요. 문의: 경희대 DX추진단 dx@khu.ac.kr

키는 이 브라우저에만 저장되고, 선택한 AI 서버로만 전송돼요. 다른 사람과 같이 쓰는 컴퓨터에서는 저장하지 마세요.

키워드 설정

관심 있는 낱말(예: 금리, 반도체, 저출생)을 넣어 두면 뉴스·사설·칼럼 탭 위쪽에 키워드 칸이 생기고, 누르면 그 낱말이 들어간 기사만 모여요. 정치·경제 같은 분야는 탭 줄의 '분야 고르기'에서 보일 것만 고르면 돼요.

내 키워드

공부 중인 자료를 넣으면 AI가 키워드를 추천해 줘요.

📚 관심 분야 논문도 보기 고르면 자료실 '논문'의 ⭐ 내 분야와 오늘 한눈에 '내 모아보기'에 나와요

저장한 키워드는 이 브라우저에 남아요. 위 👤 로그인을 하면 내 계정에 저장돼서 휴대폰 등 다른 기기에서도 그대로 보여요.
사이트는 매일 6번 정치·경제·사회·세계·IT/과학·생활 기사를 넓게 모아요. 그 안에 없는 키워드는 '네이버에서 보기' 링크로 바로 찾을 수 있어요.

🔧 운영자용 — GitHub 연결

사이트 주인만 쓰는 곳이에요. 일반 사용자는 안 열어도 돼요. 안 써도 사이트는 자동으로 잘 돌아가요.

  • 기본 키워드 바꾸기: 링크를 처음 연 사람은 아직 자기 키워드가 없어서 '기본 키워드'를 보게 돼요 (식당 메뉴판의 '오늘의 추천' 같은 것). 위에 키워드를 넣고 아래 '기본 키워드로 저장'을 누르면 이걸 바꿀 수 있어요.
  • 지금 바로 수집: 기사는 하루 6번(7·10·13·16·19·22시) 자동으로 모여요. 다음 시간까지 기다리기 싫을 때 '▶ 지금 바로 수집'을 눌러요.

처음 한 번 GitHub 토큰을 넣어야 해요.
토큰 만들기: GitHub → 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access: Only select repositories에서 이 사이트 저장소 선택 → Permissions → Repository permissions → Contents: Read and write, Actions: Read and write → Generate

토큰은 이 브라우저에만 저장돼요. 여러 사람이 쓰는 컴퓨터에서는 쓰고 나서 토큰 칸을 비우고 저장하세요.

수집은 10~20분 걸려요. 끝나면 새로고침하세요.

👥 사용자 계정 기능 연결 (운영자용, 처음 한 번)

사용자마다 로그인해서 레벨·이슈 노트·팔로우·AI 대화 기록을 따로 저장하려면, 무료 서비스 Supabase를 연결해요.

  1. supabase.com 가입 → New project 만들기
  2. 왼쪽 SQL Editor → 아래 SQL을 붙여넣고 Run
  3. Project Settings → API Keys에서 Publishable key(sb_publishable_…)를, Data API에서 Project URL을 복사해 아래에 넣기 → 설정 파일 만들기 → 열린 GitHub 화면에서 Commit
  4. Authentication → URL Configuration의 Site URL에 이 사이트 주소 넣기
create table public.user_data (
  user_id uuid primary key references auth.users on delete cascade,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz default now()
);
alter table public.user_data enable row level security;
create policy "own read" on public.user_data for select using (auth.uid() = user_id);
create policy "own insert" on public.user_data for insert with check (auth.uid() = user_id);
create policy "own update" on public.user_data for update using (auth.uid() = user_id);

anon key는 공개돼도 되는 키예요(위 SQL의 보안 규칙이 각자 자기 데이터만 보게 막아줘요). 절대 Secret key(sb_secret_…)나 service_role 키는 넣지 마세요.
